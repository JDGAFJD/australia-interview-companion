# Australia Interview Companion

A compact live-call reference with 63 questions grouped by topic, instant full-answer popups, and comma-separated OR search across questions, answers, numbers, and topics.

## Website

https://jdgafjd.github.io/australia-interview-companion/

Click a question to read its complete answer. Close with the Close control, Escape, or the backdrop. Search `tuition, accommodation` to combine matches without duplicates. Press `/` to focus search.

The four-column desktop overview fits all 63 questions at 1280 × 720. Smaller screens use fewer columns and readable text. The original source PDF, preparation notes, and confirmation placeholders are retained.

## Offline use

Download or clone this repository and open `index.html` in a browser. No dependencies, installation, account, or API required.

## Content

Answers preserve the source guide dated 29 September 2026, with line wrapping adapted for the web. Financial, visa, university, and career statements have not been newly verified during website publication.

## Hosting

GitHub Pages serves the repository root from the `main` branch. Changes pushed to that branch are automatically published.
